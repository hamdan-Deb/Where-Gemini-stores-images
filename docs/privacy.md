# Privacy Notes

Images can contain sensitive information even when that information is not obvious from the picture itself.

Examples include faces, identity documents, addresses, GPS metadata, screenshots, financial information, medical information, private messages, source code, and credentials.

## Third-party processing

If an application sends an image to an external AI provider, that provider becomes part of the data-processing boundary.

A basic review should ask:

- What data is sent?
- Is the input retained?
- Is the output retained?
- How long is it kept?
- Who can access it?
- Are prompts or metadata logged?
- Are output URLs protected?
- Are backups kept?
- Is the data used for service improvement?
- Where is the processing performed?
- Which subprocessors are involved?
- What deletion guarantees are provided?

This repository does not conclude that Prodia violates a privacy law. That would require a much more specific legal and contractual analysis.
