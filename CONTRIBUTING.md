# Contributing

Contributions should improve the evidence or make the tests easier to reproduce.

Useful contributions include:

- finding authoritative sources
- correcting outdated model names
- reproducing documented API behavior
- adding controlled observations
- pointing out unsupported claims
- improving diagrams
- documenting conflicting evidence
- improving the threat model

## Evidence standard

For a factual change, include:

1. The claim.
2. The source or observation.
3. The date checked.
4. What the evidence actually shows.
5. Any known limitations.

Primary sources are preferred.

Do not submit fabricated evidence, private data, credentials, unauthorized captures, or exploit code aimed at third-party production systems.

If new evidence changes a finding, update the evidence matrix and keep the history clear.
