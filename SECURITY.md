# Security Policy

This repository contains independent security research into AI image-processing infrastructure.

It is not a license to test systems without permission.

## Research boundaries

- Use accounts you control.
- Use synthetic or non-sensitive images.
- Do not access another user's data.
- Do not bypass authentication.
- Do not exploit production systems.
- Do not intercept other users' credentials.
- Do not perform denial-of-service testing.
- Follow provider terms and applicable law.

## Do not publish

Never commit:

- API keys
- bearer tokens
- cookies
- magic-link tokens
- session identifiers
- private images
- identity documents
- private network captures
- personal information

Sanitize captures before publishing them.
